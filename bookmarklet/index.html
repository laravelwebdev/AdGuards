🎭 Penyamaran Otomatis: Saat ditarik ke Bookmarks bar, bookmarklet akan otomatis bernama YouTube.
🔴 Trik Menyamar Sempurna (Favicon / Logo Asli YouTube di Bookmarks Bar):

Di browser seperti Chrome dan Edge, bookmarklet biasa kadang tidak menampilkan icon favicon merah. Ikuti 3 langkah cepat ini agar bookmarklet memiliki Logo Asli Merah YouTube:

  1. Buka situs youtube.com → tekan Ctrl + D untuk bookmark. Browser akan menyimpan logo resmi YouTube.
  2. Klik kanan bookmark YouTube tersebut di Bookmarks Bar → pilih Edit (Ubah).
  3. Hapus URL aslinya, lalu Paste (Tempelkan) kode bookmarklet di bawah ke kolom URL → klik Save.

✓ Selesai! Bookmark Anda sekarang 100% tampak seperti YouTube biasa lengkap dengan logo merahnya.

🎮 Tombol & Kontrol Pintas (Mode Siluman)

Klik Teks [ Terms ]

Aktivasi / Deaktivasi (Android & PC)

Ketuk/klik teks "Terms" di pojok kanan bawah peta untuk mengaktifkan/menonaktifkan. Menimpa link bawaan Google agar tidak membuka tab baru. Teks berganti menjadi "Map Terms".

Shortcut [ G ]

Lihat Titik Target (Android & PC)

Tekan tombol [G] untuk menampilkan titik lokasi target (menimpa default browser). Tahan tombol [G] untuk melihat, atau ketuk cepat untuk toggle nyala/mati.

Tahan Klik Kanan

Marker Presisi (PC Mouse)

Menampilkan titik pin biru berukuran 4px tepat di lokasi target koordinat ronde saat ini. Lepaskan klik kanan untuk langsung menghilangkan titik.

Klik Tengah Mouse

Human Pan & Zoom (PC Mouse)

Menggeser peta secara halus (curved bezier) lalu melakukan zoom bertahap santai dengan offset alami menyerupai gerak mata dan tangan manusia.

Opsi Rekomendasi (Mode Siluman): Script ditarik otomatis dari GitHub Pages. 100% silent tanpa toast notification atau alert pop-up.

  1. Buka Pengelola Bookmark Browser

    Tekan kombinasi tombol Ctrl + Shift + O di Chrome / Edge / Brave, atau klik ikon bintang di URL bar lalu pilih Bookmark Manager.

  2. Buat Bookmark Baru

    Klik titik tiga di pojok kanan atas atau klik kanan pada area kosong dan pilih "Add new bookmark" (Tambah bookmark baru).

  3. Isi Nama & URL

    Beri nama misalnya 🛡️ AdGuards, lalu tempelkan (paste) kode bookmarklet dari tab di atas ke kolom URL.

  4. Jalankan Saat Bermain

    Buka halaman GeoGuessr. Setelah permainan muncul, klik bookmark tersebut satu kali. Notifikasi popup AdGuards akan muncul di pojok kanan atas menandakan script sudah aktif!
