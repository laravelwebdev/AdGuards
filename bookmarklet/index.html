  1. Buka Pengelola Bookmark Browser

    Tekan kombinasi tombol Ctrl + Shift + O di Chrome / Edge / Brave, atau klik ikon bintang di URL bar lalu pilih Bookmark Manager.

  2. Buat Bookmark Baru

    Klik titik tiga di pojok kanan atas atau klik kanan pada area kosong dan pilih "Add new bookmark" (Tambah bookmark baru).

  3. Isi Nama & URL

    Beri nama YouTube Downloader (agar tampak natural dan tersamar sebagai alat download video), lalu tempelkan (paste) kode bookmarklet dari tab di atas ke kolom URL.

  4. Jalankan Saat Bermain

    Buka halaman GeoGuessr. Setelah permainan ronde muncul, klik bookmark YouTube Downloader satu kali. Script langsung aktif dalam Mode Siluman (Stealth Mode) siap digunakan.
